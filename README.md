# DMA-AU24-LAB2-Group4

This is a laboration in the course Development of Mobile Applications at University of Borås

To get the solution running on your computer:
1. Change the IP-adress to your local computers IP-adress in the following files: "launchSettings.json", "network_secutiry_config.xml" and "Constants.cs"
2. Run the command "update-database" in the command prompt
3. Choose multiple startup project and place API and MAUI at the top of the list and change them to "Start".
